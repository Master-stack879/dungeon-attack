# ディープドア

最大4人で協力してダンジョンを踏破する、見下ろし型のダンジョンアクション（試作版）。
PC・スマホのブラウザで遊べます。

## 遊び方

- 1人で遊ぶ：職業を選んで「出発する」
- 友達と遊ぶ：1人が「部屋を作る」→ 表示された4桁のコードを伝える → 他の人はコードを入れて「部屋に入る」→ 全員が職業を選んだらホストが「出発する」
- 職業は被りなし（剣士・弓使い・僧侶・騎士・魔法使い・盗賊・吟遊詩人・召喚士の8職業）

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印 | 画面左をドラッグ |
| 攻撃 | J / Space（長押しで連続） | 攻撃ボタン |
| スキル | K | 技ボタン |
| 道具 | L | 道ボタン |
| 必殺技 | U | 必ボタン |
| 効果音のオン/オフ | M | 右上の「音」ボタン |

## 冒険のあと

- 踏破・全滅のあと、ホストは「全員で同じ職業のままもう一度」「全員でキャラクターを変えて再挑戦」「解散する」から選ぶ
- 参加者はホストの選択を待つか、「この部屋を抜ける」で自分だけ抜けられる
- 解散すると全員がタイトル画面に戻る（解散は確認のため2回押す）

## 通信が途切れたとき

- 遊んでいる途中で通信が途切れた人は、約8秒で「通信待ち」になる。扉や報酬選びはその人を待たずに進める
- 途切れた人は、同じ部屋コードで「部屋に入る」と冒険の続き（同じ部屋・HP・強化）に戻れる（同じブラウザのタブを閉じていない場合）
- 3分たっても戻らない人は外れる
- ホストの通信が切れると全員のゲームが止まる

## 必殺技と連携

- 攻撃する・攻撃を受ける・仲間を回復や蘇生すると必殺ゲージがたまり、満タンで職業ごとの必殺技が使える
  - 剣士「大旋風」・弓使い「矢の雨」・僧侶「大いなる祈り」・騎士「不屈の城壁」・魔法使い「隕石群」・盗賊「影分身乱舞」・吟遊詩人「英雄の歌」・召喚士「大召喚」
- 1.5秒以内に2人以上が必殺技を使うと「連携必殺」、全員そろうと「全員必殺」（大ダメージ＋全員回復）
- 連携技（組み合わせで自然に起きる）
  - 盾の陰の一撃：挑発の盾を構えた騎士のそばに落ちた範囲攻撃が1.5倍
  - 挟み撃ち：騎士に引きつけられた敵を盗賊が斬ると必ず会心
  - 聖域の蘇生：僧侶の聖域の中なら蘇生が3倍速い
  - 英雄の伴奏：吟遊詩人の歌の中で必殺技を使うとゲージが3割残る
  - 魔力の共鳴：味方の弾が他の人の使い魔のそばを通ると、小さな弾が2つ追加で飛び出す
- タイトル画面の「必殺技と連携技」を開くと一覧が見られる

## 地域とイベント部屋

- 出発のたびに地域が選ばれる：試しの地下道・氷の洞窟（凍えると足が遅くなる）・溶岩城（燃える床）。雑魚もボスも地域ごとに違う
- 分かれ道に出るイベント部屋：商人（ゴールドで買い物）、祭壇（最大HPと引き換えにレア以上の報酬）、罠の回廊（20秒生き延びる。無傷ならご褒美が増える）、宝の部屋のミミック
- 確認用：アドレスの最後に `#ice` `#lava` `#crypt` を付けるとその地域から、`#ice-boss2` のように付けるとボス部屋から始まる

## 挑戦レベル

- タイトル画面で挑戦レベル（0〜10）を選べる。そのレベルで踏破すると次のレベルが解放される
- レベルが上がるごとに、厳しい条件が1つずつ積み重なる（敵のHP・回復の実・敵の数・敵の攻撃力・ボスのHP・泉と商人・敵の速さ・報酬の数・無敵時間・最終ボス）
- 協力プレイでは、ホストが選んだレベルで全員が遊ぶ

## 記録と実績

- 冒険が終わると、1人ずつの成績（与えたダメージ・撃破・蘇生など）と称号が出る
- タイトル画面の「記録と実績」で、通算成績・職業ごとの最速踏破・最近の冒険・実績を確認できる
- 実績を達成すると、新しい遺物が報酬候補に加わったり、職業の色違いが選べるようになる
- 記録は遊んだ端末（ブラウザ）ごとに保存される。協力プレイでは、各自が解放した遺物が各自の報酬候補に入る

## しくみ

- `index.html` 1ファイルで完結
- 通信は PeerJS（WebRTC）によるホスト方式。ホストの端末がゲームを計算し、参加者へ状態を配信する
- ホストの画面を閉じたりスリープさせたりすると、全員のゲームが止まる
